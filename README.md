# money-robo_news_rebuild — 발행인 로드맵 브리핑

Money-Robo 발행인이 김 연구원의 노션 데일리 리포트(2025-11-18 「기업개황 - LLM 데이터 처리」 ~ 2026-11-18 「LLM 자동 포스팅 51종」, 139건)를 여덟 스테이지 로드맵으로 정리한 정적 웹 문서입니다. 장기 목표는 [money-robo.com](https://money-robo.com/) 사이트 구조 레노베이션입니다. 기준일 2026-11-18.

## 말하는 사람

| 말풍선 | 역할 |
|---|---|
| 김 연구원 | 데일리 리포트의 결과를 요약 보고 (“~이 완료됐습니다. 이를 보고합니다.”) |
| 발행인 | 보고를 받고 코멘트·판단 |
| 처음 보는 독자 | 새로 보는 사람이 물을 질문 |
| 기록 데스크 · 요청 접수함 | 일정 기록, 수정 요청 접수 |

발행인 코멘트 앞에는 항상 김 연구원의 보고가 오며, 한 대화는 2~4턴입니다. 김 연구원 말풍선은 리포트 내용을 한두 문장으로 요약한 것이지 원문 그대로가 아닙니다.

## 파일

```
index.html       게시용 페이지 (자체 완결 HTML)
src/build.py     페이지 빌드 스크립트 — 스테이지·대화·표 내용이 모두 여기에 있음
src/base.css     기본 스타일
```

## 다시 빌드하기

```
python3 src/build.py
```

## 주의

- 숫자는 모두 데일리 리포트에 적힌 값입니다. 리포트 사이 표기가 다른 곳은 페이지의 “확인할 것”에 모았습니다.
- 테스트 서버 주소와 관리자·개발 도구 계정 정보는 옮기지 않았습니다.
- 노션 링크는 사내 워크스페이스 권한이 있어야 열립니다.
- 판단 단추와 수정 요청은 보는 사람의 브라우저(localStorage)에만 저장됩니다.
